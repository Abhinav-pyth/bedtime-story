## 🎮 How to Use Hindi Stories

### Method 1: Home Page
1. Look at the **top right** of the home page
2. You'll see a button: **🇮🇳 हिंदी** (or 🇬🇧 English if already in Hindi)
3. Click it to switch languages
4. The page will instantly update with Hindi content

### Method 2: Stories Page
1. Go to the **Stories** tab (📚 icon)
2. At the top, you'll see:
   - A badge showing: **🇬🇧 English • 20 Stories** (or 🇮🇳 हिंदी • 20 कहानियाँ)
   - A toggle button to switch languages
3. Click the toggle button to switch
4. All 20 Hindi stories will appear

### Method 3: Settings Page
1. Go to **Settings** (⚙️ icon)
2. Find the **Language / भाषा** section
3. Click either **🇬🇧 English** or **🇮🇳 हिंदी**
4. Your choice is saved automatically

## 🐛 Troubleshooting

### "I don't see Hindi stories"
**Solution:** Look for the language toggle button at the top of any page. It shows 🇮🇳 हिंदी or 🇬🇧 English. Click it to switch.

### "The text is still in English"
**Solution:** Make sure you clicked the toggle button. The button should show the language you're switching TO, not the current language.

### "I switched to Hindi but stories aren't showing"
**Solution:** This shouldn't happen anymore! The fix ensures all 20 Hindi stories load when you switch to Hindi mode. If you still see issues, try:
1. Hard refresh the page (Ctrl+Shift+R or Cmd+Shift+R)
2. Clear browser cache
3. Check browser console for errors

### "My language choice isn't saved"
**Solution:** The app uses localStorage to save your preference. If it's not saving:
1. Check if your browser allows localStorage
2. Try in a different browser
3. Make sure you're not in private/incognito mode
